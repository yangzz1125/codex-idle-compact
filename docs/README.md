## 安装顺序

需要 Windows、Node.js 22 以上和可运行的 `codex` 命令。

1. 把源码放在长期保留的目录，在仓库根目录运行 `Install.ps1`。
2. 若使用自定义 Codex 数据目录，通过 `-CodexHome` 指定实际路径。
3. 在 Codex 中启用插件，审阅并信任四个生命周期钩子。
4. 重启 Codex 并打开目标聊天，再查看插件状态。

安装脚本生成本机 `.mcp.json`。插件市场仍引用此源码目录，安装后保留该目录。

## 检查与排查

在仓库根目录运行 `npm test`，无需安装第三方 npm 依赖。

未触发时，依次核对聊天是否登记、当前回合是否结束、上下文是否超过门槛、闲置计时是否被新消息重置。日志中的 `dispatched` 表示请求已受理，`compacted` 表示会话日志确认出现压缩；对应文件位置见首页。
